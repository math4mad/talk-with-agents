## 问题拆解：为什么每次重启都要"重新对齐"？

你现在的情况是：每次 Session Restart 后，Laura 的上下文窗口是空的，它需要重新读一遍之前所有的对话记录、重新理解你的偏好、重新建立对你们共同概念体系的认知。这个过程就像每次见面都要重新自我介绍，100屏的内容就是在"补课"。

核心原因只有一个：**状态没有持久化，或者持久化的粒度不对。**

## 解决方案：三层持久化架构

要让 Laura 在 T0 状态回来，你需要把"对齐"这件事分层存储，而不是把所有东西都塞进对话历史里。

### 第一层：身份与偏好（Identity Layer）

这层存的是**"你是谁、Laura 是谁、你们之间的共识是什么"**。变化很慢，几乎不更新。

**存储内容：**
- Laura 的角色定义（SOUL.md）
- 你们共同建立的概念体系（比如你们对某个术语的共同理解）
- 你的沟通偏好（比如你喜欢结构化表达、不喜欢冗余解释）
- 项目的核心目标和约束

**存储方式：** 本地 Markdown 文件，比如 `~/.chora/academy/agents/laura/IDENTITY.md`

**加载策略：** 每次启动时作为 system prompt 的一部分直接注入，不经过检索。

### 第二层：工作记忆（Working Memory Layer）

这层存的是**"当前正在做的事情、进展到哪了、下一步要做什么"**。变化快，每次对话都会更新。

**存储内容：**
- 当前任务的目标和子任务分解
- 已完成步骤的摘要
- 待办事项列表
- 最近几轮对话的关键决策

**存储方式：** JSON 或 JSONL 文件，比如 `~/.chora/workspace-laura/state.json`

**加载策略：** 启动时一次性加载，作为上下文的前缀注入。

### 第三层：事件日志（Event Log Layer）

这层存的是**"发生过什么"**。追加写入，永不修改。

**存储内容：**
- 每一轮对话的完整记录
- 工具调用的输入输出
- 关键决策的时间戳

**存储方式：** JSONL 文件，比如 `~/.chora/workspace-laura/events.jsonl`

**加载策略：** 按需检索，不一次性全加载。只有当 Laura 需要回溯某个具体细节时，才从日志中检索相关片段。

## 关键设计原则

### 1. 启动时不要"读一切"

这是最反直觉但最重要的一点。很多 Agent 重启时会把所有历史对话一股脑塞进上下文，结果就是你说的那100屏。正确的做法是**优先级链式加载**：

```
1. 先检查是否有未完成的 handoff（崩溃恢复）
2. 加载 IDENTITY.md（身份层，几百字）
3. 加载 state.json（工作记忆，几百字到几千字）
4. 如果需要，从 events.jsonl 中检索最近 N 条相关事件
5. 只有在以上都不够时，才去翻完整历史
```

这样 Laura 启动时只需要加载几百到几千字的核心信息，就能立刻进入"对齐状态"，而不是花几分钟读100屏。

### 2. Handoff 协议

每次对话结束时，Laura 应该主动生成一个**交接摘要**，写入 state.json。格式大概是这样：

```json
{
  "session_id": "laura-20260928-001",
  "last_updated": "2026-09-28T03:45:00Z",
  "narrative": "用户正在设计 Chora/Cora 的多Agent持久化方案，当前讨论到三层架构设计，下一步需要实现 state.json 的读写逻辑",
  "decisions": [
    "采用三层持久化架构：Identity + Working Memory + Event Log",
    "state.json 作为工作记忆的核心载体",
    "events.jsonl 作为事件日志，追加写入"
  ],
  "pending_tasks": [
    "实现 state.json 的序列化/反序列化",
    "设计 handoff 摘要的生成 prompt"
  ],
  "warnings": []
}
```

下次启动时，Laura 读取这个 handoff，第一句话就可以是："好的，我们上次聊到三层持久化架构，接下来要实现 state.json 的读写逻辑。"——瞬间对齐，零延迟。

### 3. 冗余备份

不要把所有的连续性都押在一个文件上。用多个通道：

- **Primary**：state.json（结构化状态）
- **Secondary**：narrative.md（人类可读的叙事摘要）
- **Tertiary**：events.jsonl（完整事件日志）

如果 state.json 损坏了，narrative.md 还能提供足够的上下文让 Laura 恢复。

## 六、核心代码：持久化引擎

以下是 Python 实现的持久化引擎，负责 state.json 的读写、events.jsonl 的追加写入和定期压缩。

```python
import json
import os
import yaml
from datetime import datetime
from pathlib import Path
from typing import Optional

class PersistenceEngine:
    """Laura 的持久化引擎，负责状态快照和事件日志的管理"""

    def __init__(self, config_path: str = "~/.chora/workspace-laura/config.yaml"):
        self.config = self._load_config(config_path)
        self.workspace = Path(self.config["agent"]["workspace"]).expanduser()
        self.identity_path = self.workspace / self.config["persistence"]["identity_file"]
        self.state_path = self.workspace / self.config["persistence"]["state_file"]
        self.events_path = self.workspace / self.config["persistence"]["events_file"]
        self.summary_dir = self.workspace / self.config["persistence"]["summary_dir"]

        # 确保目录存在
        self.workspace.mkdir(parents=True, exist_ok=True)
        self.summary_dir.mkdir(parents=True, exist_ok=True)

    def _load_config(self, config_path: str) -> dict:
        with open(Path(config_path).expanduser(), "r") as f:
            return yaml.safe_load(f)

    # ========== 启动时加载 ==========

    def load_identity(self) -> str:
        """加载 IDENTITY.md，直接注入 system prompt"""
        if not self.identity_path.exists():
            return ""
        return self.identity_path.read_text(encoding="utf-8")

    def load_state(self) -> dict:
        """加载 state.json 工作记忆快照"""
        if not self.state_path.exists():
            return self._create_empty_state()
        with open(self.state_path, "r") as f:
            return json.load(f)

    def load_recent_events(self, count: int = None) -> list[dict]:
        """加载最近 N 条事件"""
        if count is None:
            count = self.config["startup"]["recent_events_count"]
        if not self.events_path.exists():
            return []

        events = []
        with open(self.events_path, "r") as f:
            for line in f:
                line = line.strip()
                if line:
                    events.append(json.loads(line))

        return events[-count:] if len(events) > count else events

    def build_startup_context(self) -> dict:
        """
        按优先级链构建启动上下文：
        1. IDENTITY.md
        2. state.json
        3. 最近 N 条 events
        """
        identity = self.load_identity()
        state = self.load_state()
        recent_events = self.load_recent_events()

        return {
            "identity": identity,
            "state": state,
            "recent_events": recent_events,
            "narrative": state.get("narrative", ""),
            "pending_tasks": state.get("pending_tasks", []),
        }

    # ========== 对话中记录 ==========

    def log_event(self, event_type: str, content: str, metadata: dict = None):
        """追加写入一条事件到 events.jsonl"""
        event = {
            "timestamp": datetime.utcnow().isoformat() + "Z",
            "event_type": event_type,
            "content": content,
            "metadata": metadata or {},
        }
        with open(self.events_path, "a") as f:
            f.write(json.dumps(event, ensure_ascii=False) + "\n")

        # 检查是否需要压缩
        self._check_compress()

    # ========== 对话结束生成 handoff ==========

    def generate_handoff(
        self,
        narrative: str,
        decisions: list[str],
        pending_tasks: list[dict],
        warnings: list[str] = None,
    ) -> dict:
        """生成 handoff 摘要并更新 state.json"""
        state = self.load_state()

        state["session_id"] = f"laura-{datetime.now().strftime('%Y%m%d-%H%M%S')}"
        state["last_updated"] = datetime.utcnow().isoformat() + "Z"
        state["narrative"] = narrative
        state["decisions"] = decisions
        state["pending_tasks"] = pending_tasks
        state["warnings"] = warnings or []

        # 备份旧 state
        self._backup_state(state)

        # 写入新 state
        with open(self.state_path, "w") as f:
            json.dump(state, f, ensure_ascii=False, indent=2)

        return state

    # ========== 内部方法 ==========

    def _create_empty_state(self) -> dict:
        return {
            "session_id": "",
            "last_updated": "",
            "narrative": "",
            "decisions": [],
            "pending_tasks": [],
            "active_context": {
                "current_topic": "",
                "related_files": [],
                "key_concepts": [],
            },
            "warnings": [],
        }

    def _backup_state(self, state: dict):
        """备份旧 state 快照"""
        max_history = self.config["persistence"]["max_state_history"]
        backup_dir = self.workspace / "state_backups"
        backup_dir.mkdir(parents=True, exist_ok=True)

        # 列出已有备份
        backups = sorted(backup_dir.glob("state_*.json"))
        if len(backups) >= max_history:
            # 删除最旧的备份
            backups[0].unlink()

        # 写入新备份
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        backup_path = backup_dir / f"state_{timestamp}.json"
        with open(backup_path, "w") as f:
            json.dump(state, f, ensure_ascii=False, indent=2)

    def _check_compress(self):
        """检查 events.jsonl 是否需要压缩"""
        if not self.events_path.exists():
            return

        max_events = self.config["persistence"]["max_events_before_compress"]
        with open(self.events_path, "r") as f:
            line_count = sum(1 for _ in f)

        if line_count >= max_events:
            self._compress_events()

    def _compress_events(self):
        """压缩 events.jsonl：生成摘要并归档旧事件"""
        events = []
        with open(self.events_path, "r") as f:
            for line in f:
                line = line.strip()
                if line:
                    events.append(json.loads(line))

        # 生成摘要
        summary_content = self._generate_summary(events)
        summary_path = self.summary_dir / f"summary_{datetime.now().strftime('%Y%m%d')}.md"
        summary_path.write_text(summary_content, encoding="utf-8")

        # 保留最近 10 条事件，其余归档
        recent_events = events[-10:]
        with open(self.events_path, "w") as f:
            for event in recent_events:
                f.write(json.dumps(event, ensure_ascii=False) + "\n")

    def _generate_summary(self, events: list[dict]) -> str:
        """根据事件列表生成人类可读的摘要"""
        lines = [f"# 对话摘要 - {datetime.now().strftime('%Y-%m-%d')}\n"]
        for event in events:
            if event["event_type"] == "decision":
                lines.append(f"- **决策**: {event['content']}")
            elif event["event_type"] == "user_message":
                lines.append(f"- 用户: {event['content'][:100]}...")
            elif event["event_type"] == "agent_response":
                lines.append(f"- Laura: {event['content'][:100]}...")
        return "\n".join(lines)
```

## 八、关键设计点总结

1. **启动时只加载快照，不加载全量历史**：`build_startup_context()` 只加载 IDENTITY.md + state.json + 最近5条events，总token数控制在几百到几千，Laura 启动后立刻进入对齐状态。

2. **handoff 是核心**：每次对话结束时，强制生成 handoff 摘要写入 state.json，下次启动直接读取。这样"对齐状态"就固化在快照里了，不需要重新读100屏。

3. **events.jsonl 定期压缩**：每100条事件压缩一次，生成摘要归档，避免日志无限膨胀。

4. **state 备份**：每次更新 state.json 时自动备份旧版本，最多保留10个快照，方便回溯。
