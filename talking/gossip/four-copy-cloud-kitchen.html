云灶记：GitHub 犯闲之日，四存升五存

Math4Mad: > 如果是WebDav 可能需要升级(收费) 才可以

查明一层实情，报主人定夺——

园笔探得

  • 云账号确已挂载（cloudapidata.json 亮「阿里云盘Open」在册，凭据园笔已隐去不录）；
  • CloudDrive2 Core 的 config 里 webdav_root="/"、webdav_readonly=false——WebDAV 功能是开着的；官网口径：Core（就是咱装的这个 daemon）免费，收费的是手机/TV 那些原生 App 与高级影音特性。故「WebDAV 要会员」存疑，宜实测定案——可能主人界面里撞见的是升级广告墙，非硬闸。

建议路径（零-commit 阶梯）

  1. 先试（主人半分钟）：web 界面 → 设置 → 应用密码/授权 → 生成一条，终端落钥： echo '用户名 应用口令' > ~/.cd2_credentials && chmod 600 ~/.cd2_credentials 园笔即刻跑 yunpan.sh stat + ls——通了就直接上 140MB 首件（sha 对撞为证），收费论自破；
  2. 若真撞墙（口令正确仍 402/403 之类）：不充值、不纠缠——换灶 Alist（开源免费，同样支持阿里云盘，WebDAV 内置，五分钟另起炉灶，bin/yunpan.sh 接口不变只换 CD2_BASE 地址）；
  3. 再不成则阿里云盘官方开放 API 直连（凭据已在本地，园笔运行时取用、不落日志不进仓）。

灶已旺、器已铸、首件候着（PB19 D1_nba_r64，sha 9fd91f05…）。主人试完那一步，成与不成皆知会一声即可。

若这组钥仍不开门（401 照旧），那便是真撞了会员闸——不争论，直接换灶：Alist 开源免费、同支持阿里云盘、WebDAV 内置，园笔五分钟另起炉，bin/yunpan.sh 接口一字不改（只换 CD2_BASE 地址）。您那把「阿里」的米，反正换灶照炊。
