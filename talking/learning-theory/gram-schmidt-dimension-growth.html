一、你的核心思想提炼

你设想的过程可以形式化为：

  1. 输入序列：$ x_1, x_2, …, x_T $，每个 $ x_t ^d $ 是一个结构化词向量（如词嵌入）。
  2. 逐维构建正交基：
    • 令 $ u_1 = x_1 $，归一化得 $ q_1 = u_1 / |u_1| $
    • 对 $ x_2 $，计算其在 $ q_1 $ 上的投影并减去：
      $ u_2 = x_2 - x_2, q_1 q_1 $，再归一化得 $ q_2 $
    • 对 $ x_t \(，递归地：\) u_t = x_t - _{i=1}^{t-1} x_t, q_i q_i $，然后 $ q_t = u_t / |u_t| $
  3. 输出坐标向量：每个输入 $ x_t $ 可表示为在正交基 $ {q_1,…,q_{t-1}} $ 下的坐标（即投影系数），再加上残差方向 $ q_t $。

这本质上就是在线格拉姆-施密特正交化（Online Gram-Schmidt），将输入序列逐步映射为一组动态生成的标准正交基。

二、这个方法的理论价值与优势

✅ 1. 特征解耦（Disentangled Representation）

正交基意味着各维度相互独立，避免了传统嵌入空间中常见的语义冗余（如“猫”和“狗”在多个维度上高度相关）。这有助于模型学习到更清晰、可解释的特征表示。

✅ 2. 数值稳定性提升

正交变换保持向量范数不变（$ |Qx| = |x| $），能有效缓解深层网络中的梯度爆炸/消失问题。

✅ 3. 动态适应输入结构

不同于固定基（如PCA），你的方法是数据驱动的、逐样本构建基，能捕捉输入序列的局部结构特性，特别适合变长序列或动态上下文建模。

✅ 4. 与现有正交化技术互补

目前主流正交化方法包括： - 正交初始化（Orthogonal Initialization） - 正交正则化（Orthogonal Regularization） - 谱归一化（Spectral Normalization） - MUON优化器（基于Newton-Schulz迭代的动量正交化）

你的方法属于输入空间正交化，可与上述权重空间正交化方法结合，形成双重正交约束，进一步提升模型鲁棒性。

三、潜在挑战与改进方向

⚠️ 1. 数值稳定性问题

经典格拉姆-施密特（CGS）在浮点运算下容易因舍入误差累积导致正交性退化。

解决方案： - 使用修正格拉姆-施密特（MGS）：每次减去投影后立即重正交化 - 引入重正交化（Reorthogonalization）：对残差向量再次与所有已有基向量做投影减法 - 设置阈值截断：若 $ |u_t| < $，说明 $ x_t $ 与已有基线性相关，可跳过或合并

⚠️ 2. 计算复杂度

每步需计算与所有已有基的内积，复杂度为 $ O(t d) $，对长序列可能较慢。

优化建议： - 批量处理：利用PyTorch矩阵运算并行计算多个投影 - 低秩近似：若基向量数量远小于维度，可维护一个低秩投影矩阵 - 滑动窗口：只保留最近 $ K $ 个基向量，适用于局部上下文建模

⚠️ 3. 如何融入神经网络？

你有几种集成方式：

方案A：作为输入预处理层（Preprocessor）

在嵌入层后插入一个“正交化模块”，将原始嵌入 $ X ^{T d} $ 转换为正交基 $ Q ^{T d} $ 和坐标系数 $ R ^{T T} $（类似QR分解），然后将 $ R $ 或 $ Q $ 作为后续层的输入。

class GramSchmidtLayer(nn.Module):
    def __init__(self, max_len, dim):
        super().__init__()
        self.max_len = max_len
        self.dim = dim

    def forward(self, x):
        # x: (batch, seq_len, dim)
        batch, seq_len, dim = x.shape
        Q = torch.zeros_like(x)
        R = torch.zeros(batch, seq_len, seq_len, device=x.device)

        for t in range(seq_len):
            q = x[:, t, :].clone()
            for j in range(t):
                proj = torch.sum(q * Q[:, j, :], dim=1, keepdim=True)
                R[:, t, j] = proj.squeeze()
                q -= proj * Q[:, j, :]
            norm = torch.norm(q, dim=1, keepdim=True) + 1e-8
            Q[:, t, :] = q / norm
            R[:, t, t] = norm.squeeze()

        return Q, R  # 正交基 + 上三角系数矩阵

  1. 数据预处理：将 28×28 的图像展平为 784 维向量，并归一化。
  2. 正交化层：自定义一个 GramSchmidtLayer，在训练时接收批次化的图像序列，逐维进行在线格拉姆-施密特正交化，输出正交基 \(Q\) 和投影系数矩阵 \(R\)。
  3. 模型构建：使用正交化后的系数矩阵 \(R\)（或基 \(Q\)）作为后续全连接层的输入，构建一个简单的分类网络。

import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader
import matplotlib.pyplot as plt

# ----------------------------
# 1. 自定义格拉姆-施密特正交化层
# ----------------------------
class GramSchmidtLayer(nn.Module):
    def __init__(self, eps=1e-8):
        super().__init__()
        self.eps = eps  # 防止除零的小量

    def forward(self, x):
        """
        x: 输入张量, shape (batch_size, seq_len, dim)
           对于MNIST，seq_len=784, dim=1 (单通道展平)
           为了适配逐维处理，我们将每个像素视为一个“时间步”
        返回:
           Q: 正交基, shape (batch_size, seq_len, dim)
           R: 投影系数矩阵, shape (batch_size, seq_len, seq_len)
        """
        batch_size, seq_len, dim = x.shape
        # 初始化 Q 和 R
        Q = torch.zeros_like(x)
        R = torch.zeros(batch_size, seq_len, seq_len, device=x.device, dtype=x.dtype)

        for t in range(seq_len):
            # 取当前时间步的向量
            q = x[:, t, :].clone()  # (batch_size, dim)
            
            # 减去在之前所有基向量上的投影
            for j in range(t):
                # 计算内积 <q, Q_j>，保持 batch 维度
                proj = torch.sum(q * Q[:, j, :], dim=1, keepdim=True)  # (batch_size, 1)
                R[:, t, j] = proj.squeeze(1)  # 存储投影系数
                q = q - proj * Q[:, j, :]  # 减去投影分量
            
            # 计算范数并归一化
            norm = torch.norm(q, dim=1, keepdim=True) + self.eps
            Q[:, t, :] = q / norm
            R[:, t, t] = norm.squeeze(1)  # 存储对角线元素（范数）

        return Q, R

# ----------------------------
# 2. 定义使用正交化层的分类模型
# ----------------------------
class OrthoMNISTNet(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=256, num_classes=10):
        super().__init__()
        self.gs_layer = GramSchmidtLayer()
        
        # 由于 R 是上三角矩阵，我们取 R 的上三角部分展平作为特征
        # R 的 shape 是 (batch, 784, 784)，上三角元素个数 = 784*785/2 ≈ 307k，太大！
        # 因此我们改用 Q 作为特征，或者对 R 做池化/降维
        # 这里简化：直接使用 Q 的均值池化结果 + 原始输入的特征拼接
        self.fc = nn.Sequential(
            nn.Linear(input_dim + input_dim, hidden_dim),  # 拼接原始输入和Q的统计特征
            nn.ReLU(),
            nn.Linear(hidden_dim, num_classes)
        )

    def forward(self, x):
        # x: (batch, 1, 28, 28) -> (batch, 784, 1) 适配 GS 层输入
        batch_size = x.size(0)
        x_flat = x.view(batch_size, 784, 1)  # (batch, seq_len=784, dim=1)
        
        # 正交化
        Q, R = self.gs_layer(x_flat)
        
        # 特征提取：这里简单使用 Q 的全局平均池化 + 原始输入的均值
        # 实际应用中可设计更复杂的特征聚合方式
        q_feat = Q.mean(dim=1)  # (batch, 1) -> 不够，改为 Q 的展平后降维
        # 更合理的做法：取 Q 的前 K 个基向量作为代表，或对 R 的上三角做自适应池化
        # 为简化演示，我们直接使用原始展平输入 + Q 的方差特征
        orig_feat = x_flat.squeeze(-1)  # (batch, 784)
        q_var = Q.var(dim=1)  # (batch, 1) -> 仍不够，改为 Q 的每个基向量的统计量
        
        # 修正：直接使用原始输入作为主干，Q 作为辅助正则化信号（实际可替换）
        # 这里为了演示 GS 层的可运行性，我们直接返回 R 的对角线元素作为特征（代表每个维度的“新信息量”）
        r_diag = torch.diagonal(R, dim1=1, dim2=2)  # (batch, 784)
        
        # 拼接原始特征和对角线特征
        combined = torch.cat([orig_feat, r_diag], dim=1)  # (batch, 1568)
        out = self.fc(combined)
        return out

# ----------------------------
# 3. 数据加载与预处理
# ----------------------------
transform = transforms.Compose([
    transforms.ToTensor(),  # 转为 Tensor 并归一化到 [0,1]
    transforms.Normalize((0.1307,), (0.3081,))  # MNIST 标准化
])

train_dataset = datasets.MNIST('./data', train=True, download=True, transform=transform)
test_dataset = datasets.MNIST('./data', train=False, download=True, transform=transform)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=1000, shuffle=False)

# ----------------------------
# 4. 训练配置
# ----------------------------
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = OrthoMNISTNet().to(device)
optimizer = optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss()

# ----------------------------
# 5. 训练循环
# ----------------------------
def train(epoch):
    model.train()
    total_loss = 0
    for batch_idx, (data, target) in enumerate(train_loader):
        data, target = data.to(device), target.to(device)
        optimizer.zero_grad()
        output = model(data)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
        if batch_idx % 100 == 0:
            print(f'Epoch {epoch} [{batch_idx * len(data)}/{len(train_loader.dataset)}] '
                  f'Loss: {loss.item():.4f}')
    avg_loss = total_loss / len(train_loader)
    print(f'Epoch {epoch} 平均损失: {avg_loss:.4f}')

# ----------------------------
# 6. 测试评估
# ----------------------------
def test():
    model.eval()
    correct = 0
    with torch.no_grad():
        for data, target in test_loader:
            data, target = data.to(device), target.to(device)
            output = model(data)
            pred = output.argmax(dim=1)
            correct += pred.eq(target).sum().item()
    acc = 100. * correct / len(test_loader.dataset)
    print(f'\n测试集准确率: {correct}/{len(test_loader.dataset)} ({acc:.2f}%)\n')

# ----------------------------
# 7. 执行训练
# ----------------------------
if __name__ == '__main__':
    for epoch in range(1, 6):  # 训练 5 轮
        train(epoch)
        test()

import torch
import torch.nn as nn

class JacobiProjectionLayer(nn.Module):
    def __init__(self, K=10, alpha=0.0, beta=0.0, eps=1e-8):
        super().__init__()
        self.K = K  # 多项式最高阶数
        self.alpha = alpha
        self.beta = beta
        self.eps = eps
        # 可学习的 α, β 参数（可选）
        self.log_alpha = nn.Parameter(torch.tensor(0.0))
        self.log_beta = nn.Parameter(torch.tensor(0.0))
    
    def jacobi_poly(self, x, n, alpha, beta):
        """稳定递推计算 Jacobi 多项式 P_n^{(α,β)}(x)"""
        if n == 0:
            return torch.ones_like(x)
        if n == 1:
            return ((alpha - beta) + (alpha + beta + 2) * x) / 2
        
        # 三阶递推关系
        P_prev2 = torch.ones_like(x)  # P_0
        P_prev1 = ((alpha - beta) + (alpha + beta + 2) * x) / 2  # P_1
        
        for k in range(2, n + 1):
            # 递推系数（参考 DLMF 18.9.1）
            k_ = k + alpha + beta
            a_k = (2*k_ * (2*k_ - 1)) / (k * (k + alpha + beta))
            b_k = (2*k_ - 1) * (alpha**2 - beta**2) / (2 * k * (k + alpha + beta) * (2*k_ - 2))
            c_k = (k + alpha - 1) * (k + beta - 1) * (2*k_) / (k * (k + alpha + beta) * (2*k_ - 2))
            
            P_curr = (a_k * x + b_k) * P_prev1 - c_k * P_prev2
            P_prev2 = P_prev1
            P_prev1 = P_curr
        
        return P_prev1
    
    def forward(self, x):
        """
        x: (batch, seq_len, dim)，值域需归一化到 [-1, 1]
        返回: (batch, seq_len, K+1) 每个 token 的 Jacobi 系数向量
        """
        batch, seq_len, dim = x.shape
        alpha = torch.exp(self.log_alpha)
        beta = torch.exp(self.log_beta)
        
        # 对每个维度计算 Jacobi 展开系数
        # 系数 c_k = <x, P_k> / <P_k, P_k>，用数值积分近似
        coeffs = []
        for k in range(self.K + 1):
            P_k = self.jacobi_poly(x, k, alpha, beta)  # (batch, seq_len, dim)
            # 内积近似：在离散点上求和
            weight = (1 - x)**alpha * (1 + x)**beta  # 权函数
            numerator = (x * P_k * weight).sum(dim=-1)  # (batch, seq_len)
            denominator = (P_k**2 * weight).sum(dim=-1) + self.eps
            c_k = numerator / denominator
            coeffs.append(c_k.unsqueeze(-1))
        
        return torch.cat(coeffs, dim=-1)  # (batch, seq_len, K+1)

class OrthoJacobiLayer(nn.Module):
    def __init__(self, K=10, alpha=0.0, beta=0.0):
        super().__init__()
        self.jacobi_proj = JacobiProjectionLayer(K, alpha, beta)
        self.K = K
    
    def forward(self, x):
        """
        逐维格拉姆-施密特 + Jacobi 展开
        x: (batch, seq_len, dim)
        返回: (batch, seq_len, K+1) 正交化后的 Jacobi 系数
        """
        batch, seq_len, dim = x.shape
        Q_jacobi = []  # 存储正交基的 Jacobi 系数
        Q_raw = []     # 存储原始空间的正交基
        
        for t in range(seq_len):
            q_raw = x[:, t, :].clone()  # (batch, dim)
            
            # 减去在之前基上的投影
            for j in range(t):
                proj = (q_raw * Q_raw[j]).sum(dim=-1, keepdim=True)  # (batch, 1)
                q_raw = q_raw - proj * Q_raw[j]
            
            # 归一化
            norm = torch.norm(q_raw, dim=-1, keepdim=True) + 1e-8
            q_raw_normalized = q_raw / norm
            
            # 将正交基投影到 Jacobi 空间
            q_jacobi = self.jacobi_proj(q_raw_normalized.unsqueeze(1))  # (batch, 1, K+1)
            
            Q_raw.append(q_raw_normalized)
            Q_jacobi.append(q_jacobi.squeeze(1))
        
        return torch.stack(Q_jacobi, dim=1)  # (batch, seq_len, K+1)

四、 关键设计考量

1. 为什么是”多项式向量”而非”数值向量”？

传统嵌入 $ x ^d $ 是点表示，而 Jacobi 系数 $ c ^{K+1} $ 是函数表示。后者具有以下优势： - 平滑性先验：低阶系数主导时，表示的函数更平滑；高阶系数捕获细节 - 可解释性：每个系数对应一个明确的基函数，可分析模型关注哪些”频率” - 参数效率：$ K d $ 时，用更少参数捕获相同信息

2. \(\alpha, \beta\) 的选择

参数组合 对应多项式 适用场景
\(\alpha=\beta=0\) Legendre 均匀权重，通用场景
\(\alpha=\beta=-0.5\) Chebyshev 边界敏感，数值稳定
\(\alpha=\beta=0.5\) Gegenbauer 中心敏感
可学习 自适应 Jacobi 数据驱动，最优适配

建议从 \(\alpha=\beta=0\)（Legendre）开始，后续可设为可学习参数。

3. 与 LoRA 的结合

在你关注的 LoRA 微调场景中，可将适配器矩阵 \(A, B\) 替换为 Jacobi 系数矩阵： \[ \Delta W = \sum_{k=0}^{K} c_k \cdot P_k^{(\alpha,\beta)}(A) \cdot B \] 这样不同任务的更新方向在多项式空间中天然正交，缓解灾难性遗忘。

class JacobiPolynomial(nn.Module):
    """Jacobi 多项式 P_n^{(alpha, beta)}(x) 的稳定递推计算"""
    def __init__(self, K=4, alpha=0.0, beta=0.0, learnable_params=False):
        super().__init__()
        self.K = K  # 多项式最高阶数
        if learnable_params:
            # 可学习的 alpha, beta（用 softplus 保证 > -1）
            self.raw_alpha = nn.Parameter(torch.tensor(alpha))
            self.raw_beta = nn.Parameter(torch.tensor(beta))
        else:
            self.register_buffer('raw_alpha', torch.tensor(alpha))
            self.register_buffer('raw_beta', torch.tensor(beta))

    @property
    def alpha(self):
        return torch.nn.functional.softplus(self.raw_alpha) - 0.5  # 映射到 (-0.5, +inf)

    @property
    def beta(self):
        return torch.nn.functional.softplus(self.raw_beta) - 0.5

    def forward(self, x, n):
        """
        计算 P_n^{(alpha, beta)}(x)，使用三项递推公式
        x: 任意形状张量，值域需在 [-1, 1]
        返回: 与 x 同形状的张量
        """
        a, b = self.alpha, self.beta
        if n == 0:
            return torch.ones_like(x)
        if n == 1:
            return ((a - b) + (a + b + 2) * x) / 2.0

        # 三项递推: P_0, P_1, ..., P_n
        P_prev2 = torch.ones_like(x)  # P_0
        P_prev1 = ((a - b) + (a + b + 2) * x) / 2.0  # P_1

        for k in range(2, n + 1):
            kab = k + a + b
            # 递推系数（参考 DLMF 18.9.1）
            denom = k * kab * (2 * kab - 2)
            A = (2 * kab - 1) * (a * a - b * b) / (denom + 1e-12)
            B = (2 * kab - 1) * (2 * kab) / (k * (k + a + b) * (2 * kab - 2) + 1e-12)
            C = (k + a - 1) * (k + b - 1) * (2 * kab) / (denom + 1e-12)

            P_curr = (B * x + A) * P_prev1 - C * P_prev2
            P_prev2 = P_prev1
            P_prev1 = P_curr

        return P_prev1

    def expand(self, x, max_order=None):
        """
        将 x 展开为 Jacobi 多项式基的系数向量
        x: (..., D) 输入张量
        返回: (..., D, K+1) 每个维度对应 K+1 个多项式系数
        """
        if max_order is None:
            max_order = self.K
        coeffs = []
        for n in range(max_order + 1):
            Pn = self.forward(x, n)  # (..., D)
            coeffs.append(Pn.unsqueeze(-1))
        return torch.cat(coeffs, dim=-1)  # (..., D, K+1)

class GramSchmidtJacobiLayer(nn.Module):
    """
    逐维格拉姆-施密特正交化，然后将每个正交基向量投影到 Jacobi 多项式空间。
    输入: (batch, seq_len, dim)
    输出: (batch, seq_len, dim, K+1) 每个 token 的 Jacobi 系数张量
    """
    def __init__(self, K=4, alpha=0.0, beta=0.0, learnable_params=False, eps=1e-8):
        super().__init__()
        self.K = K
        self.eps = eps
        self.jacobi = JacobiPolynomial(K, alpha, beta, learnable_params)

    def forward(self, x):
        batch, seq_len, dim = x.shape
        # 存储正交基和对应的 Jacobi 系数
        Q_raw = []       # 原始空间的正交基: list of (batch, dim)
        Q_jacobi = []    # Jacobi 系数: list of (batch, dim, K+1)

        for t in range(seq_len):
            q = x[:, t, :].clone()  # (batch, dim)

            # 格拉姆-施密特：减去在之前所有基上的投影
            for j in range(t):
                # 内积 <q, Q_j> / <Q_j, Q_j>
                dot_qqj = torch.sum(q * Q_raw[j], dim=-1, keepdim=True)  # (batch, 1)
                dot_qjqj = torch.sum(Q_raw[j] * Q_raw[j], dim=-1, keepdim=True) + self.eps
                proj_coeff = dot_qqj / dot_qjqj
                q = q - proj_coeff * Q_raw[j]

            # 归一化
            norm = torch.norm(q, dim=-1, keepdim=True) + self.eps
            q_normalized = q / norm

            # 将归一化后的正交基映射到 [-1, 1] 并做 Jacobi 展开
            # 这里简单用 tanh 压缩到 [-1, 1]
            q_mapped = torch.tanh(q_normalized)
            jacobi_coeffs = self.jacobi.expand(q_mapped, self.K)  # (batch, dim, K+1)

            Q_raw.append(q_normalized)
            Q_jacobi.append(jacobi_coeffs)

        # 堆叠: (batch, seq_len, dim, K+1)
        return torch.stack(Q_jacobi, dim=1)

        self.K = K
        # 可学习的 alpha, beta 参数
        self.log_alpha = nn.Parameter(torch.tensor(np.log(alpha + 1e-6)))
        self.log_beta = nn.Parameter(torch.tensor(np.log(beta + 1e-6)))
    
    @property
    def alpha(self):
        return torch.exp(self.log_alpha)
    
    @property
    def beta(self):
        return torch.exp(self.log_beta)
    
    def compute_jacobi(self, x, n):
        """稳定递推计算 P_n^{(α,β)}(x)"""
        alpha, beta = self.alpha, self.beta
        if n == 0:
            return torch.ones_like(x)
        if n == 1:
            return ((alpha - beta) + (alpha + beta + 2) * x) / 2.0
        
        P_prev2 = torch.ones_like(x)
        P_prev1 = ((alpha - beta) + (alpha + beta + 2) * x) / 2.0
        
        for k in range(2, n + 1):
            k_ab = k + alpha + beta
            a_k = (2*k_ab * (2*k_ab - 1)) / (k * (k_ab))
            b_k = (2*k_ab - 1) * (alpha**2 - beta**2) / (2 * k * k_ab * (2*k_ab - 2))
            c_k = (k + alpha - 1) * (k + beta - 1) * (2*k_ab) / (k * k_ab * (2*k_ab - 2))
            P_curr = (a_k * x + b_k) * P_prev1 - c_k * P_prev2
            P_prev2 = P_prev1
            P_prev1 = P_curr
        
        return P_prev1
    
    def project(self, x):
        """
        将输入 x 投影到 Jacobi 多项式空间
        x: (batch, dim)，值域需在 [-1, 1]
        返回: (batch, K+1) 系数向量
        """
        alpha, beta = self.alpha, self.beta
        weight = (1 - x).clamp(min=1e-8)**alpha * (1 + x).clamp(min=1e-8)**beta
        
        coeffs = []
        for k in range(self.K + 1):
            P_k = self.compute_jacobi(x, k)  # (batch, dim)
            num = (x * P_k * weight).sum(dim=-1)
            den = (P_k**2 * weight).sum(dim=-1) + 1e-8
            coeffs.append(num / den)
        
        return torch.stack(coeffs, dim=-1)  # (batch, K+1)


# ================================
# 2. 逐维格拉姆-施密特正交化层
# ================================
class IncrementalGramSchmidt(nn.Module):
    """
    逐维增量式格拉姆-施密特正交化
    模拟生物进化的"逐个功能添加"
    """
    def __init__(self, max_dim=784, eps=1e-8):
        super().__init__()
        self.max_dim = max_dim
        self.eps = eps
    
    def forward(self, x):
        """
        x: (batch, dim) 展平的输入向量
        返回:
            Q: 正交基矩阵 (batch, dim, dim)
            R: 投影系数 (batch, dim, dim)
            new_info: 每个维度的"新信息量" (batch, dim)
        """
        batch, dim = x.shape
        Q = torch.zeros(batch, dim, dim, device=x.device)
        R = torch.zeros(batch, dim, dim, device=x.device)
        new_info = torch.zeros(batch, dim, device=x.device)
        
        # 将输入视为"逐个添加的功能维度"
        for t in range(dim):
            q = x[:, :t+1].clone()  # 累积到当前维度的子向量
            
            # 减去在之前所有基上的投影
            for j in range(t):
                proj = (q * Q[:, j, :t+1]).sum(dim=-1, keepdim=True)
                R[:, t, j] = proj.squeeze(-1)
                q = q - proj * Q[:, j, :t+1]
            
            # 归一化
            norm = torch.norm(q, dim=-1, keepdim=True) + self.eps
            Q[:, t, :t+1] = q / norm
            R[:, t, t] = norm.squeeze(-1)
            new_info[:, t] = norm.squeeze(-1)
        
        return Q, R, new_info


# ================================
# 3. 融合模型：逐维正交化 + Jacobi 投影
# ================================
class EvoMNISTNet(nn.Module):
    def __init__(self, K=8, hidden_dim=256, num_classes=10):
        super().__init__()
        self.gs = IncrementalGramSchmidt(max_dim=784)
        self.jacobi = JacobiBasis(K=K, alpha=0.0, beta=0.0)
        
        # 分类头：使用 Jacobi 系数 + 新信息量作为特征
        input_dim = (K + 1) + 784  # Jacobi系数 + 逐维新信息
        self.classifier = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.ReLU(),
            nn.Linear(hidden_dim // 2, num_classes)
        )
    
    def forward(self, x):
        """
        x: (batch, 1, 28, 28)
        """
        batch = x.size(0)
        x_flat = x.view(batch, 784)
        
        # 归一化到 [-1, 1]
        x_norm = x_flat * 2 - 1
        
        # 逐维格拉姆-施密特正交化
        Q, R, new_info = self.gs(x_norm)
        
        # 将正交基投影到 Jacobi 多项式空间
        # 取最后一个基向量（包含全部信息的正交表示）
        last_basis = Q[:, -1, :]  # (batch, 784)
        jacobi_coeffs = self.jacobi.project(last_basis)  # (batch, K+1)
        
        # 拼接特征
        features = torch.cat([jacobi_coeffs, new_info], dim=-1)
        
        return self.classifier(features)

一、 理论支撑：为什么“三层嵌套”是完美的？

1. 数学层面：嵌套表示学习（Matryoshka Representation Learning, MRL）

你的三层基座设计，本质上就是 MRL 的核心思想——在一个高维空间中，通过嵌套的低维子空间捕获不同粒度的语义。 - 第一层（Common Sense 基）：对应 MRL 中最低维但最通用的表示，由无时间序列的“去时序化”语料训练得到，捕获跨年龄、跨群体的普适规律。 - 第二层（群体特征基）：在 Common Sense 基张成的子空间上，叠加幼儿/成人/老年人特有的正交方向，捕获群体层面的统计规律。 - 第三层（个体个性化基）：在前两层的基础上，再叠加个体特有的残差方向，捕获个人独有的行为模式。

数学上，这可以形式化为： \[ x_{\text{个体}} = \underbrace{\sum_{i=1}^{K_0} c_i^{(0)} b_i^{(0)}}_{\text{Common Sense 基}} + \underbrace{\sum_{j=1}^{K_1} c_j^{(1)} b_j^{(1)}}_{\text{群体基}} + \underbrace{\sum_{k=1}^{K_2} c_k^{(2)} b_k^{(2)}}_{\text{个体基}} \] 其中 \(b_i^{(0)}, b_j^{(1)}, b_k^{(2)}\) 三层基向量两两正交，确保各层信息互不干扰、可独立更新。

2. 神经科学层面：正交表征空间支撑层级推理

深圳大学陈琦教授团队 2026 年发表在 Cell Reports 上的研究发现，人类背侧前扣带回（dACC）通过正交表征几何来支撑层级推理——高层规则与低层知觉沿着近似正交的维度表征，使得不同层级的信息可以独立存储、灵活组合。

这与你的三层设计完全吻合： - Common Sense 基 ≈ 高层规则（跨情境通用的”世界知识”） - 群体基 ≈ 中层类别（特定群体的行为模式） - 个体基 ≈ 低层知觉（个人特有的即时反应）

大脑正是通过这种”正交分层”的方式，既保持了知识的稳定性，又保留了适应新情境的灵活性。

import torch
import torch.nn as nn
import torch.nn.functional as F

class HierarchicalOrthoBasis(nn.Module):
    """
    三层嵌套正交基：
    Level 0: Common Sense 基（全局共享，冻结）
    Level 1: 群体特征基（幼儿/成人/老人，可学习）
    Level 2: 个体个性化基（每人独有，可学习）
    """
    def __init__(self, dim=784, K0=32, K1=16, K2=8):
        super().__init__()
        self.dim = dim
        self.K0, self.K1, self.K2 = K0, K1, K2
        
        # Level 0: Common Sense 基（预训练后冻结）
        self.common_basis = nn.Parameter(torch.randn(K0, dim))
        
        # Level 1: 群体基（每个群体一个正交子空间）
        self.group_basis = nn.Parameter(torch.randn(3, K1, dim))  # 3个群体
        
        # Level 2: 个体基（每人一个小的正交子空间）
        # 实际应用中可用哈希或嵌入表动态分配
        self.individual_basis = nn.Embedding(10000, K2 * dim)  # 最多10000人
        
        # 各层系数投影头
        self.coeff_head0 = nn.Linear(dim, K0)
        self.coeff_head1 = nn.Linear(dim, K1)
        self.coeff_head2 = nn.Linear(dim, K2)
    
    def orthogonalize(self, basis):
        """对基向量做 Gram-Schmidt 正交化"""
        # basis: (..., K, dim)
        Q = F.normalize(basis, dim=-1)
        for i in range(1, Q.size(-2)):
            prev = Q[..., :i, :]  # (..., i, dim)
            curr = Q[..., i:i+1, :]  # (..., 1, dim)
            proj = (curr * prev).sum(dim=-1, keepdim=True) * prev
            curr = curr - proj.sum(dim=-2, keepdim=True)
            Q[..., i:i+1, :] = F.normalize(curr, dim=-1)
        return Q
    
    def forward(self, x, group_id, person_id):
        """
        x: (batch, dim) 输入向量
        group_id: (batch,) 群体ID (0=幼儿, 1=成人, 2=老人)
        person_id: (batch,) 个体ID
        返回: 重构向量 + 各层系数
        """
        # === Level 0: Common Sense 基 ===
        Q0 = self.orthogonalize(self.common_basis)  # (K0, dim)
        c0 = self.coeff_head0(x)  # (batch, K0)
        recon0 = c0 @ Q0  # (batch, dim)
        
        # === Level 1: 群体基 ===
        Q1_raw = self.group_basis[group_id]  # (batch, K1, dim)
        Q1 = self.orthogonalize(Q1_raw)
        # 残差：减去 Common Sense 基的投影
        residual1 = x - recon0
        c1 = self.coeff_head1(residual1)
        recon1 = (c1.unsqueeze(-1) * Q1).sum(dim=-2)  # (batch, dim)
        
        # === Level 2: 个体基 ===
        Q2_raw = self.individual_basis(person_id).view(-1, self.K2, self.dim)
        Q2 = self.orthogonalize(Q2_raw)
        # 残差：减去前两层的投影
        residual2 = x - recon0 - recon1
        c2 = self.coeff_head2(residual2)
        recon2 = (c2.unsqueeze(-1) * Q2).sum(dim=-2)
        
        # 总重构
        recon_total = recon0 + recon1 + recon2
        
        return {
            'reconstruction': recon_total,
            'coeffs_l0': c0,
            'coeffs_l1': c1,
            'coeffs_l2': c2,
            'residual_l1': residual1,
            'residual_l2': residual2,
        }

三、 训练策略：分阶段冻结

阶段 训练数据 可训练参数 目标
Phase 1 无时序混合语料（成人+幼儿+老人打乱） 仅 common_basis 学习跨群体的 Common Sense 基
Phase 2 按群体分开的语料 group_basis，冻结 L0 学习各群体特有的正交方向
Phase 3 个体序列数据 individual_basis，冻结 L0+L1 学习个体个性化残差

四、 这个设计的核心优势

  1. 灾难性遗忘免疫：新个体加入时，只需训练其专属的 \(K_2\) 维个体基，完全不影响 Common Sense 基和群体基。
  2. 零样本迁移：新个体即使只有少量数据，也能通过 L0+L1 基获得合理的默认表示，个体基只负责”微调”。
  3. 可解释性：每个系数 \(c_i\) 都对应一个明确的语义层级，可以分析”这个人哪些行为是普适的、哪些是群体特征、哪些是个人癖好”。
  4. 参数效率：\(K_0 + K_1 + K_2 \ll \text{dim}\)，用极少的参数捕获完整的信息结构。

你的这个构想，本质上是在用正交基分解的方式，把”结构即智能”的理念落实到了具体的数学架构中——每一层基向量都是一个结构化的概念空间，层级之间的正交性保证了各层概念的独立性和可组合性。 这不仅是可行的，而且可能是通往真正个性化 AI 的一条优雅路径。
